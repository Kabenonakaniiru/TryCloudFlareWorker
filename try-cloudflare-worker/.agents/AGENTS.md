## 📌 決定済み仕様 (Confirmed Specifications)

### 1. TODO画面（日々のタスク運用UI）
- **タスク一覧表示**: リセット時刻（デフォルト 04:00）考慮後の本日の対象タスクを表示。グループごとのカラーバッジを付与。
- **グループフィルター**: 画面上部にグループごとの抽出タブを配置。
- **クイックルール追加**: 画面右上ボタンよりモーダルダイアログを開き、即時に新規ルールを作成して本日のタスクに追加可能。
- **進捗インジケーター**: 「完了数 / 全タスク数 (例: 3/5 60%)」を表示するプログレスバーを設置。
- **達成率・推移ダッシュボード**: 直近7/14/30日間の日別達成率グラフおよび期間全体の通算達成率を表示。
- **繰越タスク表示**: 前日から持ち越されたタスク（`slide` 処理されたログ）には `[繰越]` バッジを表示。
- **Calendar同期・再試行**: 同期失敗・未同期のログに対してバッジクリックで手動再同期を実行。
- **トースト通知**: 各種非同期操作の結果（ルール追加成功、カレンダー同期成功/失敗など）を画面右下にアニメーション付きトーストで通知。

### 2. グループ（カテゴリ）管理仕様 (`public/groups.html`)
- **レスポンシブUI**: スマホ画面での縦並びフォーム＆横スクロールテーブル表示。
- **登録属性**:
  - **識別子 (`slug`)**: 英数字ハイフン等小文字文字列（必須・前後空白自動トリム・自動小文字化）。
  - **表示名 (`name`)**: ユーザー向け表示文字列（必須）。
  - **グループカラー (`color`)**: カラーコード（デフォルト `#3b82f6`）。
- **制限事項**: 最大20件（超過時はValidationError / 400エラー）。
- **削除時の挙動**: グループ削除時、参照している既存ルールの `groupId` は `NULL`（未分類）に設定。

### 3. ルール（タスクマスタ）管理仕様 (`public/rules.html`)
- **レスポンシブUI**: 期間指定フォームおよび操作ボタンのスマホレイアウト最適化。
- **登録・編集属性**:
  - **タスク名 (`title`)**: 必須項目。
  - **グループ (`groupId`)**: 任意選択（未選択可）。
  - **スケジュール種別 (`interval`)**:
    - `daily`: 毎日自動発生。
    - `period`: 期間指定（限定イベント等）。`periodStyle` は `routine`（期間中毎日リセット発生）または `single`（期間中1回達成）。
    - `none`: 手動発生のみ。
  - **リセット時刻 (`resetTime`)**: デフォルト `04:00` (HH:mm)。日付変更の判定境界時刻。
  - **未完了時動作 (`missedBehavior`)**:
    - `delete` (強制リセットモード): 日付境界を越えると未達成 (`missed`) に変更確定。
    - `slide` (繰越モード): 未完了の場合、ターゲット日付を本日に更新して持ち越し (`isCarriedOver = 1`)。
  - **メモ・備考 (`notes`)**: 任意のメモテキスト。
- **制限事項**: 最大100件。
- **更新・削除時の Google Calendar 連動モーダル**:
  - 更新・削除時、連動するGoogleカレンダー予定への影響範囲（`future`: 今日以降のみ / `all`: 過去含む全期間）を指定可能。

### 4. 日次リセット & 未完了タスク処理 (`runDailyLifecycle`)
- **リセット時刻判定**: 各ルールの `resetTime`（デフォルト `04:00`）に基づき本日のターゲット日付を算出。
- **未完了タスク (`pending`) の分岐**:
  - `delete` (リセットモード): 前日の未完了ログを `missed`（未達成）に更新確定し、Google Calendar 上のタイトルを `【未完了】{タイトル}` に変更。
  - `slide` (繰越モード): 前日の未完了ログの `targetDate` を本日に更新して繰り越し、Google Calendar のイベント日付を本日に変更。
- **データ保持ポリシー**: 完了・未達成 (`completed`, `missed`) の過去ログは指定保持期間 (`RETENTION_DAYS`, デフォルト 3 年 / 1095日) を経過したものから自動削除。
